# Repository instructions

## Operational record

This system's operational facts (hosts, Dokploy apps, environment variable names, backups, DNS and providers) are recorded in the private [Nilotik/docs](https://github.com/Nilotik/docs) repo at `estates/mogz/README.md`. When a change here alters any of them, update that page in the same session and set its `Last verified` date. Never write secret values there.
